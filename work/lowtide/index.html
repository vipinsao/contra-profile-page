The brief

The problem

A meditation teacher opening a new retreat house wants to sell a few small weekends from one page. Guests need to choose a date and a private or shared room, a room must never be sold twice, and everything has to run through the Kajabi checkout they already use.

The idea

Build it as a working prototype rather than a mockup: real date and room selection, live availability, a waitlist when a room is full, and a registration form. Then label every block with the Kajabi feature that powers it, so the real build is a set-up job, not guesswork.

How the story plays

Beat by beat.

01 · 0:02

A page built from the host’s own content

Hero, key facts, what’s included, the weekend schedule, the teacher and an FAQ. Calm, coastal and easy to read on any screen.

02 · 0:13

Dates and rooms with real availability

Three weekends each track their own places. In January the private room is sold out, so its button becomes Join the waitlist instead of a dead end.

03 · 0:26

Registration that Kajabi keeps

Dietary needs, meditation experience, how you’ll arrive and anything the host should know. In Kajabi these are custom checkout fields, saved on the guest’s contact record.

04 · 0:36

Payment through the existing checkout

No new payment setup. The host’s Kajabi checkout, receipts and payment settings stay exactly as they are, with the booking summary beside the form.

05 · 0:42

Confirmation and next steps, automatically

Confirmation email, a tag for that date and room, and a reminder with directions and a packing list 7 days before. The room count drops the moment someone books.

06 · 0:57

Build notes for the handover

One switch labels every block with the Kajabi feature behind it, so the host can see exactly how their page is wired and update it later.

How it maps to Kajabi

Every block has a Kajabi home.

On the pageIn Kajabi
Retreat landing pageLanding Page built from the host’s copy and photos
Retreat datesA set of Offers for each weekend, so places are counted per date
Private and shared roomsOne Offer per room type with a quantity limit (3 private, 4 shared beds)
Sold out → waitlistThe Offer’s sold-out page, set to a waitlist Form that tags the guest
Registration detailsCustom checkout fields: Select, Radio buttons, Text area
PaymentThe host’s existing Kajabi checkout and payment settings
ConfirmationOffer automations: send email, add tag for date and room
Reminder, 7 days beforeEmail scheduled to that weekend’s tag, with directions and packing list

Launch test plan for the real build

  • A test purchase for every room on every date
  • A refund, and the place returning to stock
  • Quantity limit reached → sold-out page → waitlist
  • Custom fields saved on the contact
  • Confirmation and reminder emails delivered

Checked on this prototype

  • Form validation and error messages
  • Keyboard use and visible focus
  • No layout breaks with build notes on
